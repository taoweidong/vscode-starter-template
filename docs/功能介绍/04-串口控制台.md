# 04 · 串口控制台

> 「串口服务器」树视图 + 独立控制台页面：录入串口服务器（串口参数 / 自动登录），
> 连接后下发命令、实时查看输出流、复用历史命令。密码只存 VSCode SecretStorage，
> 数据文件与日志零明文。

## 如何使用

1. 活动栏「扩展模板」→「串口服务器」视图；
2. **录入服务器**：标题栏 ＋ 或「打开串口控制台」——控制台页面内表单
   （名称 / 串口 / 波特率 / 数据位 / 停止位 / 校验位 / 流控 / 换行符 / 自动登录 / 备注）；
3. **连接**：树视图单击服务器（或右键「连接并打开控制台」/ inline 🔌 按钮）；
4. **下发命令**：控制台页命令输入 → 回车；输出流实时渲染（自动滚动可暂停）；
5. **历史命令**：自动去重（trim 精确匹配）、MRU 置顶、上限 200 条；
   单击填入、双击直发、可单条删除或清空；
6. **删除服务器**：树右键（模态确认，同时清除其保存的密码）。

## 相关设置与数据落点

- 设置：`extStarter.serialConsoleEnabled`（默认开启；关闭时串口命令提示在设置中开启）；
- 数据文件：工作区 `.vscode/serial-servers.json`（原子写 + 损坏自动备份 `.bak`）；
  未打开工作区时退回全局存储（Memento）；
- 密码：`SecretStorage`（键 `extStarter.serialServer.<id>.password`）；自动登录时序：
  连接后 800ms 发用户名、再 500ms 发密码，凭据不进历史。

## 常见问题

- **「串口控制台功能已关闭」**：设置里开启 `extStarter.serialConsoleEnabled`；
- **连接失败 / 输出乱码**：核对波特率 / 校验位 / 数据位与设备一致；换行符按设备要求选择；
- **关闭面板**：自动断开串口连接（状态机驱动，重连恢复）。
