# 01 · 启动脚本与环境信息

> VSCode 窗口加载完成即自动执行（无需打开文件夹、无需点击插件——装了就生效）：
> 先运行「初始化脚本」（内置演示：向输出通道打印 Hello World），随后「环境检测」
> （探针注册表），全过程逐行打印在输出通道中。

## 如何使用

1. 安装扩展后**打开任意 VSCode 窗口**——启动任务自动开始（活动栏「扩展模板」→「环境信息」视图可实时看到分组结果）；
2. 查看控制台：`Ctrl+Shift+P` → 「Extension Starter: 打开环境信息输出」；
3. **全量重检**：「环境信息」视图标题栏 ↻；
4. **单探针重检**：单击任一探针条目（如 Python）只重检该项；
5. 自动执行可通过设置 `extStarter.runStartupTasks` 关闭（关闭后仅手动触发）。

## 检测内容（7 项）

| 条目     | 来源                                  | 说明                     |
| -------- | ------------------------------------- | ------------------------ |
| Python   | `py -3` → `python` → `python3` 回退链 | 探针注册表定义           |
| Node.js  | `node --version`                      |                          |
| npm      | `npm --version`                       |                          |
| Java     | `java -version`（stderr）→ `javac`    | 提取引号内版本号         |
| Git      | `git --version`                       |                          |
| 操作系统 | `os.type()/release()` + 架构          | 系统信息项，不可单击重检 |
| VSCode   | `vscode.env.appName` + 版本           | 系统信息项               |

状态语义：条目 `ok / missing`；任务级 `ok`（全部就绪）/ `warn`（有缺失）/ `error`（执行异常）。

## 相关设置与数据落点

- 设置：`extStarter.runStartupTasks`（默认开启）；
- 无数据落盘（结果在内存 + 输出通道；环境快照见「环境初始化」）。

## 常见问题

- **命令探测失败但命令明明可用**：探测要求退出码为 0；失败命令即使 stdout 有内容也不采纳（打印帮助文本的典型误判已排除）；
- **不想每次打开 VSCode 都探测**：关闭 `runStartupTasks`，需要时点 ↻。
