# 06 · 拷贝示例（右键复制）

> 右键把内容「拷贝出来」到剪贴板——与草稿箱「落盘」形成对照的最基础示例
> （剪贴板写入 `vscode.env.clipboard.writeText`）。

## 如何使用

| 入口                  | 操作             | 结果                                                     |
| --------------------- | ---------------- | -------------------------------------------------------- |
| 编辑器选中文本 → 右键 | 「复制选中文本」 | 精确复制选区（不 trim），提示含字符数                    |
| 资源管理器右键文件    | 「复制文件内容」 | 文件文本内容入剪贴板；**多选批量**以 `=== 路径 ===` 分隔 |
| 资源管理器右键文件    | 「复制文件路径」 | 绝对路径入剪贴板；多选每行一个                           |

## 防护规则（复制文件内容）

- 单文件上限 **1MB**（超出跳过并警告）；
- **二进制防护**：文件头 8KB 出现 NUL 字节视为二进制，跳过并警告；
- 批量时单个失败不中断其余复制，结束后汇总提示「已复制 N 个，跳过：…」。

## 常见问题

- **「编辑器中没有选中文本」**：先选中文本再右键；
- **复制出的内容为空**：查看是否命中跳过规则（大小 / 二进制），有警告条说明。
