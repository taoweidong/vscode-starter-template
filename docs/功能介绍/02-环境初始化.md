# 02 · 环境初始化

> 步骤清单式编排（「环境初始化」视图）：确认工作区 → 创建构建产物目录 → 写入环境快照。
> 支持整体执行与单步重跑，单步失败不阻断后续步骤。

## 如何使用

1. 活动栏「扩展模板」→「环境初始化」视图；
2. **全部执行**：标题栏 ✓（全部初始化）按钮；
3. **单步执行 / 重跑**：单击任一步骤（或步骤条目 inline ▶ 按钮）；
4. 结果即时反映在步骤状态上：idle → running → done / failed（含耗时与信息）。

## 内置步骤（3 步）

| 步骤         | 行为                                                         | 产物                            |
| ------------ | ------------------------------------------------------------ | ------------------------------- |
| 检查工作区   | 未打开文件夹时失败（提示先打开）                             | —                               |
| 构建产物目录 | 创建 `.ext-starter/` 目录                                    | `.ext-starter/`                 |
| 环境快照     | 运行环境检测并把结果写入快照（优先复用启动任务已缓存的结果） | `.ext-starter/environment.json` |

机制要点：单步互斥（整体执行期间单击被忽略并提示）、步骤超时 120s 裁决为失败、
失败不阻断后续、步骤注册表驱动（加步骤 = 数组加一项）。

## 常见问题

- **单步执行「毫无反应」？** 整体执行进行中会被互斥忽略——同时有提示信息；
- **快照里的检测结果和「环境信息」视图不一致？** 快照是执行时刻的复用/探测结果，点重跑即可更新。
