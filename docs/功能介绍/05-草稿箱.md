# 05 · 草稿箱（右键登记）

> 8 条右键入口把「选中的内容 / 文件 / 文件夹」一键登记到工作区草稿数据文件——
> 「宿主如何拿到编辑器 / 资源管理器上下文并写入存储」的完整示例。
> v2.2.3 起：selection 草稿**保存完整选中文本**（`content` 字段，64K 字符上限并显式
> 标记截断），`title` 仅作摘要；并发登记 / 多窗口手改经串行化读-改-写保护。

## 如何使用

| 入口                  | 操作                                      | 结果                                           |
| --------------------- | ----------------------------------------- | ---------------------------------------------- |
| 编辑器选中文本 → 右键 | 「登记选中文本到草稿箱」                  | 新增一条 selection 草稿（标题=摘要）           |
| 编辑器选中文本 → 右键 | 「追加选中文本到最近草稿」                | 内容追加到最近一条草稿（草稿箱为空则降级新增） |
| 编辑器右键（无选区）  | 「登记文件到草稿箱」（编辑器右键第 3 项） | 新增当前文件的 file 草稿                       |
| 资源管理器右键文件    | 「登记文件到草稿箱」（单选或多选批量）    | 每个文件一条 file 草稿（目录项跳过）           |
| 资源管理器右键文件夹  | 「登记文件夹内容到草稿箱」                | 一条 folder 汇总草稿（文件清单，上限 50）      |
| 编辑器标题栏          | 「登记文件到草稿箱」                      | 当前打开文件的 file 草稿                       |

## 数据与文件落点

- 数据文件：工作区 `.vscode/ext-starter.drafts.json`（原子写、损坏自动按空数据继续）；
- 上限 100 条，超出丢最旧；未打开工作区时功能不可用（有提示）。

## 常见问题

- **「未打开工作区，草稿箱不可用」**：打开一个文件夹后再使用；
- **数据文件想直接编辑**：可以——格式为 `{ schemaVersion, entries: [...] }`，
  手改后重新登记即重新加载（无外部 watcher，不会自动刷新）。
