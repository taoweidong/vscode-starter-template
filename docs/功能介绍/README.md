## 全局设置（3 项）

| 设置项                            | 默认 | 说明                                            |
| --------------------------------- | ---- | ----------------------------------------------- |
| `extStarter.runStartupTasks`      | 开启 | 激活时自动执行启动任务（初始化脚本 + 环境检测） |
| `extStarter.serialConsoleEnabled` | 开启 | 串口控制台功能开关（关闭时串口命令给出提示）    |
| `extStarter.buildApiBaseUrl`      | 留空 | 构建任务 HTTP 接口基地址；留空 = 内置打桩模拟   |
