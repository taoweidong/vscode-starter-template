# 05 · 草稿箱与右键菜单

> 右键菜单示例的教学载体：8 条入口（编辑器右键 4 + 资源管理器右键 3 + 编辑器标题栏 1）
> 统一登记到工作区 `.vscode/ext-starter.drafts.json`。教学价值在「宿主如何拿到
> 编辑器 / 资源管理器上下文并写入存储」这条链路。

## 代码地图

| 职责                             | 文件                                               | 关键符号                                                                          |
| -------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------- |
| 数据服务（原子写 / 上限 / 容错） | `src/extension/features/drafts/draftBoxService.ts` | `DraftBoxService` `DraftEntry`                                                    |
| 命令实现（上下文采集）           | `src/extension/commands/draftCommands.ts`          | 4 个命令：`draftSelection` / `appendDraftSelection` / `draftFile` / `draftFolder` |

## 核心机制

- **上下文采集**（`draftCommands.ts`）：
  - 编辑器侧：`window.activeTextEditor` 的选区文本 + 文件名（`currentSelection()`）；
  - 资源管理器侧：命令收到 `(uri, uris[])` 两参——第一个是被右键资源，第二个是
    Ctrl/Shift 多选集合（`draftFile` 据此区分单文件 / 批量登记）；
- **数据形状**：`{ schemaVersion: 1, entries: [{ id, kind, title, detail, createdAt }] }`，
  `kind` 取 `'selection' | 'file' | 'folder'`；头部插入、上限 100 条裁剪最旧；
- **可靠性**：`writeJsonAtomic` 原子写；文件缺失 / 损坏按空数据继续且**原文件不动**；
  加载时逐条过滤非法条目（缺 id/title 丢弃）。

## 扩展实操

### A. 新增一条右键入口（以「编辑器右键登记全文件内容」为例）

1. `src/extension/constants.ts` 的 `COMMAND` 加 ID：
   `draftWholeFile: 'extStarter.draftWholeFile'`；
2. `package.json` 的 `contributes.commands` 加声明（title 走 `%command.draftWholeFile.title%`
   并在 `package.nls.json` / `package.nls.zh-cn.json` 各加一条文案）；
3. `contributes.menus['editor/context']` 加条目（`when` 控制可见性，选区类用
   `editorTextFocus && editorHasSelection`）；
4. `draftCommands.ts` 实现并 `register(COMMAND.draftWholeFile, ...)`——上下文采集直接复用
   `currentSelection()` / `currentFileUri()`。

门禁第 ⑥ 步校验「constants ↔ manifest ↔ register」三方闭合，漏一处立刻红。

### B. 改草稿箱行为

- 上限 / 摘要长度 / 文件夹批量上限：`draftBoxService.ts` 顶部常量
  （`MAX_DRAFTS` / `TITLE_LIMIT` / `FOLDER_BATCH_LIMIT`）；
- 数据落点改名：`constants.ts` 的 `draftsFileName` + `DEFAULT_DIRTY_IGNORES` +
  `.gitignore` 三处字面量同步（见开发指南 README 铁律 3）。

## 常见坑

- 未打开工作区时 `fileUri === undefined`，所有命令统一提示「草稿箱不可用」——新增命令
  别忘了同样的判空；
- `explorer/context` 的 when 可用 `listMultiSelection` 区分单选 / 多选场景（现配置已示范）；
- 草稿箱没有外部 watcher（刻意简化，见 `serverStore.ts` 同款取舍）——外部手改文件需
  手动触发（重新登记即可，load 幂等）。
