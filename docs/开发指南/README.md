## 30 分钟上手路径

1. **跑起来**：`npm install && npm run gate` → VSCode 打开项目按 `F5`（详见
   [../操作指导/01](../操作指导/01-环境准备与代码下载.md)）；
2. **认架构**：读根目录 README「目录结构与架构」——记住两条边界规则：
   `src/extension/**` 只碰 `vscode`，`src/webview/**` 不碰 `vscode`，唯一跨侧契约是
   `src/webview/protocol.ts`；
3. **抄样板**：每个功能的「扩展实操」都是从仓库内现有样板出发的复制-修改：
   启动脚本抄 `helloTask.ts`、表单领域抄 `serverSchema.ts`、Webview 页面抄 `apps/gallery/`；
4. **交作业**：改完跑 `npm run gate -- --fast`，按 [agent.md 版本号规约](../../agent.md)
   升版本 + 记 CHANGELOG，再提交。

## 全仓库通用的三条铁律

1. **单一来源**：命令 / 视图 / 配置 / 存储 ID 只在 `src/extension/constants.ts` 定义，
   `package.json` contributes 与之闭合（门禁第 ⑥ 步静态校验，漏一处立刻红）；
2. **跨侧契约**：宿主 ↔ 页面消息必须走 `protocol.ts` 的联合类型 + 运行时守卫，
   禁止绕过守卫直接读消息字段；
3. **工作区数据文件三处同步**：新增落盘到 `.vscode/` 的数据文件，必须同时更新
   `constants.ts`、`DEFAULT_DIRTY_IGNORES`（字面量，无 glob）、`.gitignore`——
   否则「用过一次 → 分支编译永远被脏检查自阻断」。
