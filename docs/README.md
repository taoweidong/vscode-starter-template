# 文档总入口（docs/）

> 本仓库全部文档按 **四层结构** 组织，自上而下从「跑起来」到「为什么这么设计」。
> 主入口是仓库根的 [`README.md`](../README.md)（功能一览 / 架构 / 快速开始）；
> 本文件是**文档层的导航中心**——按需取用，每层索引都能独立查阅。

## 文档分层地图

```text
docs/
├── README.md            ← 你在这里：导航中心（本文件）
├── 操作指导/            第一层 · 上手与调试：克隆到 F5 全流程，30 分钟跑通
├── 功能介绍/            第二层 · 功能说明：每个功能怎么用（使用者视角）
```

### 快速二次开发（最短路径）

1. 读根目录 [`agent.md`](../agent.md)（强制约定：门禁 / 测试协议 / **版本号规约**）；
2. 选「抄写样板」对照 [开发指南](开发指南/README.md)：
   - 加启动脚本 → 抄 `helloTask.ts`（[指南 01](开发指南/01-启动任务与环境探针.md)）
   - 加 Webview 页面 → 抄 `apps/gallery/`（[指南 06](开发指南/06-Webview页面与表单基座.md)）
   - 加带表单的领域 → 抄 `serverSchema.ts`（[指南 06](开发指南/06-Webview页面与表单基座.md)）
   - 加命令 / 右键菜单 → （[指南 07](开发指南/07-命令视图与i18n.md)）
   - 加拷贝类命令 → 抄 `copyCommands.ts`（[指南 05](开发指南/05-草稿箱与右键菜单.md)）
3. `npm run gate -- --fast` 全绿 → 按版本号规约升版 + 记 CHANGELOG → 提交。

## 文档维护约定

- **单一事实源**：功能用法以本目录「功能介绍」为准，代码结构以根 `README.md` 为准，
  强制约定以根 `agent.md` 为准——其余文档引用而不复制；
- 每层目录有自己的 `README.md` 索引；跨层引用一律用相对链接（有脚本校验可达性）；
- 新增功能 = 「功能介绍」加一篇 + 「开发指南」加/改一篇 + 根 README 功能表同步。
