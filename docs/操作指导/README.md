# 操作指导目录

本目录存放 **vscode-starter-template** 的详细操作指导，面向第一次接触本项目的开发者（含 AI 编码代理）。

## 文档清单

| 序号 | 文档                                           | 内容                                                           | 适合场景       |
| ---- | ---------------------------------------------- | -------------------------------------------------------------- | -------------- |
| 01   | [环境准备与代码下载](01-环境准备与代码下载.md) | Node/Git/VSCode 安装验证、克隆仓库、安装依赖                   | 第一次拿到项目 |
| 02   | [开发与调试步骤](02-开发与调试步骤.md)         | F5 调试、断点、体验六大视图、调试循环、常见问题                | 开始动手开发   |
| 03   | [插件开发指南](03-插件开发指南.md)             | 基于模板开发自己的插件：改模型/加字段/换数据源/加命令/打包发布 | 二次开发       |

> 建议按 01 → 02 → 03 顺序阅读，全程约 30 分钟；每篇都可以独立查阅。
> **功能级二次开发文档**（代码地图 / 扩展实操 / 测试 / 常见坑，按功能逐篇）见
> [`../开发指南/`](../开发指南/README.md)。

## 说明

- 文中截图为 **SVG 矢量示意图**（VSCode Dark+ 主题风格），与实际界面在字体/细节上可能有差异，操作路径与菜单结构一致。
- AI 编码代理请先阅读仓库根目录的 [`agent.md`](../../agent.md)——其中包含「每次对话结束前必须执行 `npm run gate` 质量门禁 + 单元测试」的强制协议。
- 需求细化、缺陷分析、技术选型（Vue 3 / 全量单元测试 / 一键打包离线 .vsix）与实施路线图见 [`../需求与优化方案/`](../需求与优化方案/README.md)。
- 项目主文档见根目录 [`README.md`](../../README.md)，架构与扩展点以主文档为准。
