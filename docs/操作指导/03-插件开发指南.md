# 03 · 插件开发指南

> 目标：把这个「模板」变成「你的插件」。本文是**二次开发总入口**——身份改造、
> 必读约定与发布清单；每个功能的具体扩展实操见 [`../开发指南/`](../开发指南/README.md)。
> 全程遵循 `agent.md` 约定：**每次改动收尾前执行 `npm run gate`**。

## 0. 先理解模板架构

v1.0.0 起模板收敛为「4 个可抄的示例 + 1 套自洽基座」：

```text
src/extension/（宿主侧，只 import vscode）
  index.ts        组装入口（窗口加载完成即激活：onStartupFinished）
  constants.ts    命令/视图/配置/存储 ID 单一来源
  commands/       命令按场景分组（功能页面 / 串口 / 草稿箱）
  features/       drafts 草稿箱 / init 任务编排 / build HTTP 弹框 / serialConsole 真实业务
  tasks/          启动任务框架（TASKS 注册表 + TaskRunner + probes 探针注册表）
src/webview/（Vue 3，禁止 import vscode；唯一跨侧契约 protocol.ts）
  pages.ts 页面注册表 / host/ 控制器 / components/ SchemaForm / ui/ 设计系统 / apps/ 页面
```

**四类示例模式**（照抄对象）：可插拔探针（环境信息）、任务编排（环境初始化）、
异步长任务（分支编译）、真实业务（串口控制台）——每个功能的代码地图与扩展实操见
[`../开发指南/01`～`05`](../开发指南/README.md)。

## 1. 改成你的插件身份

| 字段          | 说明                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------- |
| `name`        | 插件英文标识（npm 规则：小写+连字符）                                                     |
| `displayName` | 市场显示名——走 `package.nls.json` / `package.nls.zh-cn.json` 的 `%extension.displayName%` |
| `publisher`   | 你的发布者 ID（vsce 创建：`npx vsce login <id>`）                                         |
| `repository`  | 已指向本仓库，改成你的 fork 地址（`homepage` / `bugs` 一并改）                            |
| `icon`        | 已内置 `media/icon.png`（128×128）；换图标改 SVG 后跑 `npx tsx scripts/generate-icon.ts`  |

界面品牌（活动栏标题、命令分类、配置节标题）全部在两份 nls 文件里，改这两处即可；
**ID 前缀**（`extStarter`）在 `src/extension/constants.ts` 的 `CONFIG.section` 与
manifest 各 ID 中——门禁前缀校验是动态读取的，整包改名只需改这两处 + 全局替换。

> 改 ID 前缀属破坏性变更（major），并要处理旧数据迁移——参考
> `src/extension/services/legacyMigration.ts` 的现成模式。

## 3. 质量门禁与测试

- **每次收尾**：`npm run gate`（协议见 `agent.md`；9 步 fail-fast，快速迭代 `-- --fast`）；
- **加业务逻辑时**：优先写单元 / 组件测试（`src/test/unit/**/*.spec.ts`，Vitest 不启动
  VSCode；`vscode` 模块由测试桩替换，桩只增不减）；宿主集成用例在
  `src/test/extension.test.ts` 补 `suite`；
- **测 UI**：Vue 组件有 @vue/test-utils 用例可仿写；Webview 页面另有 Playwright e2e
  （`tests/e2e/`，含 codicon 字体加载断言）。

## 4. 打包发布

```bash
npm run gate            # 门禁全绿后再打包
npm run package:vsix    # 一键：完整构建 + vsce 打包 → release/<name>-<version>.vsix
                        # Windows 可双击根目录 package.bat（支持 --clean 清空归档）
npx vsce publish        # 发布到市场（需 publisher 账号 + PAT）
```

- vsce（`@vscode/vsce`）已内置在 devDependencies，打包 / 发布都**无需全局安装**；
- 产物统一归档到 `release/`（gitignore / vscodeignore 双排除，根目录整洁）；
- 版本号：**每个代码提交按变更幅度升版并记 CHANGELOG**（`agent.md` 版本号规约）。

核对清单：`publisher` 已改 ✓ / 128×128 图标 ✓ / `repository` 指向你的仓库 ✓ /
nls 两份文案已替换品牌 ✓ / `npm run gate` 全绿 ✓。
