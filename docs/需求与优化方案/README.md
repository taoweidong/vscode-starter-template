## 决策摘要

| 项       | 决策                                                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 技术栈   | **TypeScript 全量化**（源码 / 脚本 / 测试）+ **Webview 页面全部 Vue 3**（runtime-only + Vite 多入口）                                               |
| 视觉     | **VSCode 原生设计系统**：语义令牌映射 `--vscode-*`，自研轻量组件，不引入通用 UI 框架                                                                |
| 测试     | **全量单元测试**：Vitest（单元 + Vue 组件）+ 保留宿主集成；`agent.md` 写入强制协议（每轮对话结束 / 提交前必须执行并通过单元测试；新增代码测试先行） |
| 打包     | **一键离线 .vsix**：`npm run package:vsix`（`@vscode/vsce` 内置，免全局安装），门禁含 `vsce ls` 内容校验                                            |
| 范围边界 | Vue 只覆盖 Webview 页面；6 个原生 TreeView 保持 VSCode Extension API                                                                                |

## 结论速览

- **P0 缺陷 5 项**：损坏文件自动移走并清空（`jsonFileStore.ts:14-51`）、非原子写（`:33-37`）、`storagePath` 可越界工作区（`package.json:430` + `extension.ts:135`）、扩展字段被 4 处白名单丢弃（README「加字段三步」承诺失实）、分支编译在不受信任工作区执行任意脚本；
- **P1 缺陷 17 项、P2 30+ 项**：详见 [02](02-现状差距与缺陷分析.md)；
- **根因 6 条**：持久化契约过窄 / Schema 只到渲染层 / 生命周期静态绑定 / 命令基于旧快照 / 任务无生命周期契约 / 门禁与测试面向演示仓库；
- **两项新增需求的现状差距**：当前**没有**不依赖 VSCode 下载的单元测试层（26 个用例全部为宿主集成）；当前**无法**一条命令产出 .vsix（vsce 不在 devDependencies，`npm run package` 只做构建）。
