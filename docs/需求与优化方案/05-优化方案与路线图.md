> 执行基准：[01 需求](01-需求细化.md) / [02 差距](02-现状差距与缺陷分析.md) / [03 架构](03-技术选型与架构.md) / [04 设计系统](04-VSCode原生设计系统.md)。

> 全程执行 `agent.md` 质量协议：**每轮对话结束 / 提交前单元测试必须通过；新增代码测试先行**（见 §10）。

## 1. 优化原则

1. **先安全后体验**：数据不丢（M1）优先于一切 UI 工作；
2. **测试先行**：每个任务的第一步是写失败用例（P0/P1 对应用例见 §6 测试矩阵）；
3. **小步可验证**：每个任务独立可合并、可回滚；门禁 + 单测全绿才算完成；
4. **承诺对齐**：修完一个承诺（加字段 / 换源 / 加命令 / 加任务 / 加页面）立即补回归测试与文档，不留漂移；
5. **文档随行**：代码合并的同批次更新 README / agent.md / 操作指导 / CHANGELOG。
